# Weather App

Sleek, modern weather UI built with React + Vite + TypeScript. Uses mock data but easy to plug in a free weather API.

Commands:
- npm install
- npm run dev (start dev server)
- npm run build (build)
- npm run test:unit (run unit tests)
- npm run test:e2e (run Playwright E2E tests)
- npm run test:coverage (coverage)

This project includes Vitest unit tests and Playwright E2E tests.
